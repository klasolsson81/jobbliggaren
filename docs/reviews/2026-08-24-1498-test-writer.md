## 5. `StripDates_MasksASlashRangeInsideProse`

**Altitude is right.** Asserting through `ReviewText.ContainsMeasurableDigit` rather than on the mask
string is correct: `StripDates`' output is read by nothing else, and `ContainsMeasurableDigit` is the
only consumer — verified by consumer map (`ContentRules.cs` lines 28, 44, 250, 391 are the four
readers, all through `ContainsMeasurableDigit`). Asserting on the mask string would pin an
intermediate no production caller sees.

**m-2 (Minor) — one control is not the missing one.** Both `true` rows are *within-input* controls
("a number survives elsewhere in the bullet", "a bullet with no date"). Neither crosses the direction
the widening actually risks: a bullet whose **only** digits form the newly-masked shape and which is a
genuine quantified result. Measured — three constructed bullets flip `true` → `false` under R3:

```
Sänkte kostnaden 1200/50 – 3000 kr per enhet.   ContainsMeasurableDigit  old=True  new=False
Ökade svarstiden 2000/95 – 3000 ms.             old=True  new=False
Hanterade 1500/25 – 4000 ärenden.               old=True  new=False
```

`\d{4}` in the point lists is unrestricted (unlike `Year()`), so `NNNN/NN – NNNN` is masked whatever
the digits mean. **This is an extension of an already-accepted residual, not a new class** — measured:
`Sänkte kostnaden 1200 – 3000 kr per enhet.` is `False` on **both** trees, because the pre-existing
`\d{4} – \d{4}` branch already ate it. That precedent is why this is Minor and not Major.

**The CTO's OMÄTT-3 was discharged literally while its property went unmeasured.** The bind asked for
*"R3 maskerar inget som inte är ett datum"*, instrumented as "run the suite before/after R3". The
suite contains no bullet of the newly-masked shape, so a green suite says nothing in that direction —
a control that does not cross the threshold it is named for, which is this lane's signature failure.

**Owed row (in the same theory):**

```csharp
// THE OVER-REACH DIRECTION, and it must be measured rather than derived: \d{4} in the point lists
// is unrestricted, so the row grammar eats NNNN/NN – NNNN whatever the digits mean.
[InlineData("Hanterade 1500/25 – 4000 ärenden.", ???)]
```

Pick the polarity deliberately: `true` makes it a guard (and requires narrowing the slash point to
`(?:19|20)\d{2}/\d{2}`, a production change); `false` makes it a **priced, named residual** in
`DatePatterns`' own residual list beside "Mars/Maj", `13/2020` and `2005 - 2010,`. Either is a valid
outcome. Leaving it unmeasured is not.
