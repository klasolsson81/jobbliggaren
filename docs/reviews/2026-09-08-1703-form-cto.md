## CTO-rekommendation

### Beslut D1 — Approach (A), with the prop named for the caller's fact

**The catalogue's rows suppress the CTA link. `CriterionAdLines` gains a fourth required prop:**

```ts
readonly actionOfferedByCaller: boolean;
```

`CriterionRow` passes `true` (it renders the "Ändra" control itself). `CriteriaSummary` and the
detail page pass `false`. The flag **gates the `<Link>` only — never the string choice**: at N=1 the
catalogue still renders the whole `ads.adsTooBroad` sentence (refusal + reason + advice), minus the
shortcut.

**Two bindings that are easy to get wrong and are therefore explicit:**

1. It gates **only the three `ads.matchingTooBroadCta` links** (lines 148, 168, 213). It must
   **never** reach `tWatch("matchNudgeCta")` → `MATCH_SETTINGS_HREF` (line 229): that is a different
   action, on a surface the catalogue does not offer, and gating it would delete a live way forward.
2. It is **required**, not optional-with-default. `adviceStatedByCaller` is required for the same
   reason — a default is how the fourth surface silently gets the wrong answer.

### Beslut D2 — Approach (A), with a NEW key in the catalogue's own namespace

**`CriteriaSection` computes `adviceStatedByCaller = items.length > 1` once**, threads it through
`CriterionRow` under the same name at every hop, and renders its own advice line after `</ul>`, gated
on `anyTooBroad && adviceStatedByCaller` — the same conjunction and the same order as
`criteria-summary.tsx:189`.

**The block advice carries no link.** D1's reasoning applies unchanged one level up: the action is in
every row.

**The copy is a NEW key under `pages.foretag.criteria.ads`, sv + en**, following the delivered

### Motivering mot principer

- **SRP (Martin 2017, kap. 7) — one module, one change-reason.** `variant`, `adviceStatedByCaller`
  and `actionOfferedByCaller` change for three different reasons: a surface gaining a company list; a
  list crossing N=1; a caller gaining or losing an edit affordance. Three reasons, three flags. The
  existing docblock already forbade folding two of them; a third fact folded into either is the same
  defect with a new name.
- **DRY as one home per knowledge piece (Hunt/Thomas 1999, kap. 7).** The seven-answer honesty ladder
  has one home, and #1703 makes it three consumers rather than three copies — the extension of ADR
  0139's *"Båda ytorna läser samma källa"* from the source to the rendering. The copy likewise: the
  catalogue's advice sentence belongs in the namespace that owns this vocabulary.
- **DDD / ubiquitous language (Evans 2003, "Ubiquitous Language").** `pages.foretag.criteria` **is**
  the branschbevakning context's own vocabulary — which is why `/oversikt` reads *from* it
  (`criteria-summary.tsx:88–90`) and not the reverse. Making the catalogue read `oversikt.*` inverts
  that ownership and hands a presentation namespace authority over the context's copy.
- **Intention-revealing names (Martin 2008, kap. 2; kap. 4 "comments do not make up for bad code").**
  With a third consumer, `variant="summary"` on a catalogue page is disinformation, and a docblock
  explaining that "summary" means "standalone" is the smell rather than the fix. Hence the rename in
  in-block 2.
- **ADR 0047 (flow comprehension).** The dead-end rule is **satisfied by the caller, not waived**:
  `true` is a claim that a way forward is rendered adjacently. The self-link is worse than absent —
  it is a control describing an action it does not perform, and unlike the sub-nav's active item
  (M-6) it announces nothing.
- **YAGNI / KISS.** No shared predicate module for `length > 1` — see the rejected alternatives.

### Avvisade alternativ

**D1 (B) — a third `CriterionAdLinesVariant` value `"catalogue"`.** Rejected. The variant docblock
states that it decides the antecedent *and nothing else*; a `"catalogue"` value would make the union
answer two questions, and the two disagree — the catalogue is standalone (no company rendered) **and**
action-offering. One enum cannot say both, which is exactly the #1707 failure the
`adviceStatedByCaller` split was created to end. It would also make the union non-orthogonal: a
future standalone surface without an edit control would have no value to pass.

**D1 (C) — let the self-link stand.** Rejected, and this is the snabblösning of the set. Zero code
and a visible defect: a call to action that navigates nowhere, ~200 px from a real control bearing
the same Swedish word, on a civic surface whose whole premise is "svårt att göra fel" (AGENTS.md §1).
ADR 0047 exists because three green gates missed exactly this class.

**D1 (D-variants) — an `href` prop, or a CTA that focuses the row's Ändra button.** Rejected. An
`href` prop parameterises something with one true answer and invites a second destination nobody
decided — the drift the extraction closes. A "link" that moves focus instead of navigating is not a
link, and inventing an interaction pattern for one state on one surface fails KISS.

**D2 (B) — always hoist, with a block advice carrying only the action.** Rejected on its own terms.
The hoist rule rests on **two** arguments, and only one is about duplication:
`criteria-summary.tsx:74–75` also says *"At one row there is nothing to hoist it out of."* That half
is copy-independent, so rewriting the sentence does not license always-hoisting. It would also
falsify the prop docblock's "exactly when the caller renders more than one row" for no gain.

**D2 (C) — always `true`, no block advice.** Rejected twice over. It passes `true` for a claim the
caller does not make, which is a lie in the prop's own vocabulary — and the prop's history is that
deriving it from anything but its stated meaning put the refusal on screen twice. It also deletes the
only sentence that says *what to change*, leaving "Ändra" as an affordance with no direction.

**D2 (A′) — reuse `oversikt.criteriaSummary.tooBroadAdvice`.** Rejected. Three reasons, strongest
last: its "får inga tal **här**" is deictic and was written about another block; it rewords the
refusal the rows now carry verbatim above it (#1707's shape at N>1); and it inverts the namespace
ownership the delivered code already established in the other direction.

**Extracting `length > 1` + `some(tooBroad)` into a shared module.** Rejected — for now. Two call
sites, and CLAUDE.md §3.6 carries the house's own Rule-of-Three calibration (*"only when the same
filter is used in 3+ places"*). The drift harm here is layout-only, not two surfaces disagreeing
about a number, which is what licensed the `CriterionAdLines` and `CriterionBreadth` extractions at
two and four. The rule's single home stays the prop's docblock, cited by pointer (#1173). **Revisit
at a third caller, or the first time the predicate itself changes** — that second trigger is real: it
has already changed once, in its first week.

### Trade-offs accepterade

- **A fourth boolean prop on a component that already has two.** Four props is not a design axis to
  minimise; three independent facts collapsed into two flags is. The cost is one docblock paragraph;
  the alternative is the #1707 class.
- **A flag exercised in exactly one state family, on one surface.** `actionOfferedByCaller=true` only
  changes rendering in the three too-broad branches at N=1 on the catalogue. Accepted: the states are
  reachable and honest, and both polarities are pinned (M-4's existing `/oversikt` assertions pin
  `false`; the new catalogue test pins `true`).
- **A hotspot edit to `messages/{sv,en}.json` (§6.5).** Accepted: the session owns the hotspot for
  this PR and the prompt measured no competing open PR. The alternative was a foreign-namespace read
  that inverts ownership.
- **Two independent `items.length > 1` expressions across two files.** Accepted per the extraction
  refusal above, with the named revisit trigger.
- **Rows grow from a measured 93 px.** The list at N=20 grows from a measured 2 014 px. That is
  `design-reviewer`'s veto, not mine; the number is handed to her as a datum, not as a finding.

     Generalise to a standalone surface's rows; the argument survives verbatim, only the noun changes.

     is. Extend.
   - `criteria-section.tsx:28` — *"section body on `/foretag`"* is **measured false** (M-5). Correct

7. **New `criteria-section.test.tsx`** (M-3: nothing pins the catalogue today). Four arms, fixtures
   built to the schema's own refinements (`tooBroad ⇒ magnitude === null`) so the premise is one
   production produces (§5 `Tests:`): (a) N=1 too-broad → the **whole** sentence in the row, **zero**
   `a.jp-nudgelink`, and the "Ändra" control present — ADR 0047's pin in the catalogue's own form;

   bevakningen" links anywhere; (c) nothing refused → no advice line; (d) a counted number renders
   `linkLabelStandalone` (never "från dessa företag") and links via `buildCriterionAdsHref`.
8. **Surface 1 is unchanged, and the proof is mechanical:** `criteria-summary.test.tsx` runs green
   with **no assertion edited** (M-4). If any of those four CTA assertions has to move, the delta has
   changed `/oversikt` and this ruling has been exceeded — stop and re-raise rather than editing the

9. **DoD §8 point 4 — a newly reachable non-resting state.** This is the only surface where a watch is
   edited, and ADR 0139 records that materialisation on edit *(ii)* is **not built** — so edit → save

   delta makes it reachable **by the user's own action, one click away**, for the first time. It must
   be among the states rendered for `design-reviewer`, not reasoned about.
