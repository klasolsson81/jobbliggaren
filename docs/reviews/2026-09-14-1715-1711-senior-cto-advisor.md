## CTO-rekommendation — #1715 (b)

### Beslut
**G2 — split gate**, in the refined form below: one state sentence per arm, the remedy clause stated once. Not G1, not G3.

### Motivering mot principer
- **SRP (Martin 2017, kap. 7):** the two states have two change-reasons in `CriterionMatchingAdSetResolver`. Arm A is guard 1 (companies axis, `SetTooLarge` before any count). Arm B is guard 3 (`magnitude.Magnitude > MaxSetSize` = 2 000, ads axis, on a *counted* magnitude). Guard 1 and `MaxSetSize` move independently — two sentences, two homes.
- **DRY (Hunt/Thomas 1999):** one home per *knowledge piece*, not one sentence per screen region. The remedy ("Färre branscher eller kommuner ger färre företag") **is** one knowledge piece and stays one string, read by both arms — which is also why it must not be inlined into both sentences (that is the verbatim 40-word repetition design-reviewer measured, one axis up).
- **Ubiquitous language (Evans 2003):** each sentence names the number *it* is about. "får inga tal här" is true of an arm-A row (guard 1 refuses matching before any count, so both numbers are absent — measured: `ads.tooBroad ⇒ matching.tooBroad`) and false of an arm-B row. Splitting the gate makes the delivered arm-A copy true again **without changing a byte of it**.

### Avvisade alternativ
**G1 (one sentence for both arms).** The union is not a natural kind: arm A's property is "more companies than we can count ads for", arm B's is "more ads than we can grade". A sentence spanning both either asserts A's property of a B row, or retreats to something that no longer says which number is missing — and a civic utility that has a number owes the reader *which* one is absent. G1 is also already delivered and already failed: `criteria-section.test.tsx:240-243` states the defect in its own comment — *"identifies its set by PROPERTY … which this watch is not one of"*. Advice about a set the reader's watch is not in is not advice. Over-DRY: two knowledge pieces forced into one home.

**G3 (narrow to `ads.tooBroad`).** Measured ADR 0047 dead end — the arm-B row on `/oversikt` at N>1 then has no CTA (`tooBroadCta` is dropped whenever `shortRefusal`) and no advice. It re-opens design-reviewer B2, which was closed by measurement, trading a copy defect for an interaction defect. Rejected outright.

### Gate (both surfaces, identical expressions)
```ts
const anyAdsTooBroad = items.some((i) => i.ads.tooBroad);
const anyMatchingOnlyTooBroad = items.some((i) => i.matching.tooBroad && !i.ads.tooBroad);
```
`!i.ads.tooBroad` is the `sharedRefusal` collapse one axis up: when a row refuses both, the block says it once, exactly as the row does. Render order = the rows' line order: ads sentence, matching sentence, then the remedy (catalogue) / the `Ändra bevakningen` link (`/oversikt`) **once**. One `<p>` per surface — `jp-criteria-advice` / `jp-ov-criteria__advice` untouched, no CSS, no design token (no §12 class).

## CTO-rekommendation — #1711

### Beslut
**B — split key.** The dialog keeps the decomposed count under a noun that is true for a pick; `/foretag/sok` is deliberately **not** carried along. Not A, not C.

### Motivering mot principer
- **Ubiquitous language (Evans 2003):** after B, each *phrase* has exactly one meaning. `"valda branscher"` = picked nodes, and only on `/foretag/sok`, where every counted node is visible as a named chip; bare `"branscher"`/`"kommuner"` = raw leaves, and only on the breadth line; `"val"` = a pick. Nothing means two things anywhere.
- **The kommun axis decides the branch.** On SNI, a decomposed count under "bransch" is polysemous-but-true (a huvudgrupp *is* a bransch; `sniHelp` says so). On kommun it is simply **false** — a län is not a kommun under any reading. So design-reviewer's second branch ("en gemensam räkneregel") cannot rescue it: a common rule would have to move `/foretag/sok` to raw leaves, re-opening #999 finding 4 and B-2's measurement. Distinct nouns is the only branch that closes both axes.
- **SRP (Martin 2017, kap. 7):** "how many did the user pick" is a property of the draft (picker header, clear affordance, chip parity); "how wide is this watch" is a property of the saved criterion (four read surfaces). Two questions, two vocabularies, two keys.

### Avvisade alternativ
**A (dialog counts raw leaves under the same nouns).** It gives the phrase `"valda branscher"` **two** meanings — raw in the dialog, decomposed on `/foretag/sok` — which is the reported defect relocated across pages rather than closed, and it regresses #999 finding 4's semantics in the dialog ("52 valda branscher" for one click on a section). Rejected.

**C (show both: "1 val · 4 branscher").** The middle dot is **bound as the axis separator** by three delivered docblocks (`criterion-breadth.tsx`, `criterion-row.tsx`, `criteria-card.tsx`: "joins the two axes … a layout glyph, not copy"). C reuses that glyph to join two *levels* on *one* axis, two clicks from the line that uses it the other way — a reader who has learned the dot reads the picker header as two axes. And the extent question is already answered in the dialog by `dialog.previewChosen` ("Ditt urval matchar {count} företag."), which is the **operative** width: both refusals key on magnitude (guard 1 on companies, guard 3 on `MaxSetSize` ads), never on leaf count. C pays two numbers per `aria-live` announcement for the number that does *not* predict the refusal. Rejected.

**Also considered and rejected:** moving the breadth line to "branschkoder" (register jargon against the civic-tone bar, and no parallel exists on the kommun axis, where the falsehood actually lives); extending the pick-noun to `/foretag/sok` (the summary chip sits in a mixed chip wall where "12 val" loses its axis — the one thing a chip must carry — and the popover's count is anchored by visible named referents, so no contradiction can be *rendered* there; extension is speculative scope buying a new defect, YAGNI).

### Keys and exact copy
`messages/{sv,en}/pages.json` → `foretag.criteria`:
- `sniPickedCount` **new**
  sv: `{count, plural, one {# val} other {# val}}`
  en: `{count, plural, one {# selection} other {# selections}}`
- `kommunPickedCount` **new**
  sv: `{count, plural, one {# val} other {# val}}`
  en: `{count, plural, one {# selection} other {# selections}}`
- `kommunSelectedCount` **deleted** (sv + en) — its one consumer moves, so it would be an orphan.
- `sniSelectedCount` **untouched** — its two `/foretag/sok` consumers (`bransch-popover.tsx:105`, `foretag-sok-searchbar.tsx:483`) keep it.

Two notes for the implementer, both deliberate: the sv plural block keeps **identical arms** (neuter "val" is uninflected in the plural) for locale parity with en — do not "simplify" it to `{count} val`, or a future wording change lands a missing selector on one side only. And the two axis keys stay **separate** despite identical values, matching the delivered `sniSelectedCount`/`kommunSelectedCount` split: two axes, two change-reasons.

Call sites: `criterion-dialog.tsx:176` → `tc("sniPickedCount", { count: sniPicked })`; `:193` → `tc("kommunPickedCount", { count: kommunPicked })`. `sniPicked`/`kommunPicked` stay decomposed. `criterion-breadth.tsx` unchanged (B-2 holds).

### In-block-fixar (same PR, #1711 half)
- `criterion-dialog.tsx:171-175` — **delete** the last sentence "One key, one semantic: both surfaces now count decomposed nodes." (two keys now, and the semantic is carried by the noun). Keep the #999 provenance and the first sentence, which is now what the noun itself says.
- `criterion-breadth.tsx:30-31` — **delete** "A future harmonisation toward the picker's semantics must therefore not carry these surfaces with it without re-measuring the collision (#1711 owns that divergence)." It becomes a forward pointer into nothing (AGENTS.md §1.6). Keep lines 27-29 (the raw-leaf bind, which is the guard). One replacement sentence is permitted and should state the closed rule, not the history: the second count is named "val", never "bransch" or "kommun".
- `criterion-breadth.test.tsx:62-63` — "#1711 owns the divergence" is falsified; the guard stays. Replace that clause with the resolution: the divergence is closed by vocabulary, not by harmonisation (#1711).
- `foretag-sok-searchbar.tsx:481-483` comment ("The SAME key the popover header uses…") — **survives verbatim.** Do not sweep it; both `/foretag/sok` consumers still share `sniSelectedCount`.
- New `criterion-dialog.test.tsx` must pin the two states the old copy got wrong, not just the new string: a whole huvudgrupp → `"1 val"` **and** the dialog text must not match `/vald(a)? bransch/`; a whole län → `"1 val"` **and** no match for `/vald(a)? kommun/`. Plus that `sniPicked` is still decomposed (one click on a huvudgrupp is `1`, not `4`) — otherwise the test passes equally under option A and measures nothing.

### Trade-offs accepterade
The dialog no longer states extent in branscher/kommuner. Accepted: the row states it after saving, and `previewChosen` states the width in företag, which is the quantity both refusals actually key on.
