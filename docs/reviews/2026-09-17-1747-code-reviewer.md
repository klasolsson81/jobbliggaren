## Round 1 — Major

### 1. "as the role production migrates with" is false for the Identity context

`DropAuthProviderColumnsMigrationTests.cs:16` and `:52-54`. Measured: production migrates the
Identity context in `Jobbliggaren.Migrate`'s **bootstrap mode with master credentials** —
`Program.cs:361-363`, and the comment two lines above gives the reason (`CREATE ON DATABASE`,
Npgsql #1770). The app role is precisely the role production does **not** migrate this context
with. **The sibling test's identical sentence is true, but for `AppDbContext`**, which
`RunSchemaAsync` runs with `MIGRATE_APP_CONNECTION_STRING`; the sentence was transferred to a
context where it inverts.

### 2. The DropIndex rationale claims a failure mode the engine cannot produce

`:26-28`. Measured three ways: (a) the index cannot survive a successful `Up` regardless of
`DropIndex`, because Postgres drops indexes involving a dropped column automatically — this is
the decisive argument and does not depend on EF details; (b) "silent" does not hold either —
EF generates `DROP INDEX` without `IF EXISTS`, so a wrong name gives 42704 and an aborted
migration; (c) 6a writes `AspNetUserLogins`, so an index on `AspNetUsers` cannot collide with it.

### 3. "a cascade off the dropped unique index would take the account with it"

`:21-23` and `:229-230`. `DROP INDEX ... CASCADE` drops *dependent objects*, never table rows, and
EF's `DropIndex` never generates `CASCADE`. The fourth mutant (an `Up` that also empties the
table) proves the assertion carries weight, but it does not prove the cascade mechanism.

### 4. The §5 `Tests:` paragraph names the wrong actor

`:42-44`. `AddAuthProviderToUser.cs:15-22` adds the column `nullable: false, defaultValue: "Local"`
— Postgres writes `'Local'` into every existing row. That is a writer, in `src/`. Further, the
deleted configuration set `.HasDefaultValue(AuthProvider.Local)`, making the property
`ValueGeneratedOnAdd`; since `AuthProvider.Local == 0 == default(AuthProvider)`, EF sends no value
on `CreateAsync` and the **store default** writes the column — exactly the mechanic the surviving
`CreatedAt` docblock spells out for `now()` in the same file. §5 `Tests:` requires the test to
**name the actor**, so the wrong actor is not cosmetic.

### 5. "A rollback is the operator's only way out of a bad deploy"

`:24-25`. `docs/runbooks/release-checklist.md:2527-2528` — *"rollback är en image-tagg — **för kod,
aldrig för schema**"*. `vps-deploy-stack.md:266-277` enumerates the three ways out at a schema-gate
refusal; running `Down` is none of them, and `Jobbliggaren.Migrate` has no rollback mode at all.
