### Motivering mot principer
- **SRP and CCP at PR level (Martin 2017, ch. 7 and 13).** One change-reason means one PR. The constants, pins, mirror and their record change and revert together. The repo squash-merges, so only a PR boundary survives to `main`.
- **DRY applied to knowledge (Hunt/Thomas 1999).** Each knowledge piece has one home:
  - every decision lives in (22);
  - the markers and #734's row point to it;
  - the session's parts never restate sa's text (the restatement that drifts is #1173's failure).

  Three providers' constants look alike, but they are three pieces of knowledge, so none is shared.
- **Fitness functions (Ford/Parsons/Kua 2017).** The exact-key pins with literal values are a triggered fitness function on the request shape. R3's mutations show that each pin can fail.
- **Measurement validity.** RFC 6749 §3.1 makes the probe binary, since an unrecognised parameter MUST be ignored. Only a control in the same sitting lets a page be credited to the parameter.
- **Twelve-Factor III (Config).** Config is what varies between deploys. `prompt` must not vary, so it belongs in code (sa condition 1, da R1).
- **Test pyramid (Cohn 2009).** The unit pins gate. One observe-only e2e line is the thin top.

### Avvisade alternativ
- **(b) as first drafted: ship LinkedIn's undocumented `prompt` and keep it on a box reading.** It puts an undocumented parameter in an auth adapter before anything shows that it works. No control is possible after the rollout, because the box then runs only the new build (sa Q6). It is exactly the dormant machinery that #1888 and (21) deleted.
- **da R7's minted probe:** see decision 2.
- **A shared `Prompt` constant or enum, or `prompt` as an `IOptions` value.** No provider documents a shared meaning, so a shared constant is DRY misapplied to code that only looks alike. A setting would let one environment stop asking, or send `none`. That is the same reason CLAUDE.md §11 keeps the reserved-recipient set out of `IOptions`.
- **More than one PR (code now and docs later, or one PR per provider).** ADR 0065 forbids a docs-only PR, and each split duplicates the panel and (22).
- **A panel round on C1 before the answers:** see decision 1.
- **Writing #734 row 12 now:** see decision 4.
- **The session adapting sa's text to an end state she did not write.** That would put unsigned security prose inside a signed block.
